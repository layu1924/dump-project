# QA Monitoring Center — Bug Lifecycle Tracker

Aplikasi web berbasis Laravel untuk mencatat, memantau, dan melacak siklus hidup temuan *bug* (Bug Lifecycle) beserta visualisasi sebaran tingkat keparahan (*Severity*).

## Fitur Utama
- Autentikasi pengguna (Register & Login) dengan latar belakang interaktif.
- Dashboard ringkasan metrik temuan bug (*Total Temuan*, *Open/Need Fix*, *Closed/Fixed*).
- Grafik visualisasi sebaran *Severity Bug* (Tinggi, Sedang, Rendah).
- Daftar pelacakan, pencarian, dan pencatatan laporan bug baru.

## Tech Stack
- **Backend:** Laravel 13 (PHP 8.3+)
- **Frontend:** Blade, Tailwind CSS, Vite
- **Database:** MySQL
